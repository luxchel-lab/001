# ArchiColor AI — бэкенд Decor8.ai

Страница `/AI`: клиент загружает фотографию своей комнаты, выбирает оттенок
в палитре ArchiPaint и видит свои стены, перекрашенные этой краской. Мебель,
пол и потолок остаются нетронутыми — это примерка краски, а не выдуманный
интерьер.

Перекраска выполняется через [Decor8.ai](https://api-docs.decor8.ai/),
метод `POST /change_wall_color`. Ключ API живёт только на сервере: браузер
обращается к нашим эндпоинтам, а не к провайдеру.

## Как это работает

```
браузер  ──POST /api/archicolor/generate──►  PHP-бэкенд
         (фото + артикул оттенка)             │
                    1. проверяет файл, снимает EXIF, ужимает до 1600 px
                    2. берёт HEX из каталога по артикулу (браузеру тут не верим)
                    3. списывает примерку с лимита пользователя
                    4. Decor8Client → POST https://api.decor8.ai/change_wall_color
                       { input_image_url | input_image, wall_color_hex_code }
                    5. скачивает результат на наш домен (иначе не будет ни скачивания, ни CORS)
                    6. ImageAnalyzer: сравнивает результат с исходным фото,
                       берёт изменившиеся точки — это и есть стена
                    7. k-means в CIE Lab по стене → как краска легла + ΔE к выкрасу
                    8. Palette: ближайшие оттенки ArchiPaint по ΔE2000
                                              │
браузер  ◄──────────── JSON: ссылка на картинку + разбор стены к заказу
```

Шаг 7–8 — та же математика, что на странице «Подбор цвета»
(`assets/js/podbor.color.js`), только выполненная в PHP: `lib/archicolor/Color.php`
повторяет матрицы sRGB↔XYZ, осветитель D65 и формулу CIEDE2000 один в один,
чтобы ΔE на двух страницах сайта совпадали.

Считаем на сервере намеренно: результат Decor8 лежит на их CDN, и `canvas`
в браузере «пачкается» кросс-доменной картинкой — прочитать пиксели он не даст.

## Как находим стены

Маску стен провайдер не отдаёт, но она и не нужна: `/change_wall_color`
меняет только стены, поэтому мебель, пол и потолок в ответе совпадают
с исходным кадром пиксель в пиксель. Мы сравниваем два изображения точка
за точкой и берём в разбор те, где ΔE2000 больше `wall_diff_delta_e` (по
умолчанию 6). Размеры кадров могут не совпасть — координаты пересчитываются
пропорционально.

Если изменилось меньше `wall_min_share` кадра (2%), значит стен на снимке
провайдер не нашёл. Тогда разбирается весь кадр, а в ответе поднимается
флаг `wall.coverage.fallback` — страница показывает предупреждение,
а не выдаёт разбор дивана за разбор стены.

## Установка

1. Скопируйте на сайт `ai/`, `api/`, `lib/`, `assets/`.
2. Создайте ключ в личном кабинете Decor8.ai.
3. Задайте его переменной окружения — это надёжнее файла:

   ```
   DECOR8AI_API_KEY=sk-…
   ARCHICOLOR_PUBLIC_BASE_URL=https://archipaint.ru
   ```

   Либо скопируйте `lib/archicolor/config.local.php.example`
   в `lib/archicolor/config.local.php` и заполните его.
4. Убедитесь, что каталог `upload/archicolor` доступен веб-серверу на запись.
5. Проверьте окружение:

   ```bash
   php tools/archicolor-selftest.php
   php tools/archicolor-selftest.php --remote   # живой вызов, тратит генерацию
   ```

6. Поставьте уборку старых файлов в cron:

   ```
   17 4 * * * php /var/www/archipaint/tools/archicolor-gc.php
   ```

### Требования

PHP 7.0+, расширения `gd`, `curl`, `mbstring`; `exif` желательно — без него
фотографии с телефона могут прийти повёрнутыми.

В `php.ini` проверьте `upload_max_filesize` и `post_max_size` (не меньше 12 МБ)
и `max_execution_time` — генерация занимает до 60 секунд, а таймаут запроса к
Decor8 по умолчанию 180 секунд.

## Эндпоинты

### POST /api/archicolor/generate

`multipart/form-data`:

| поле | обяз. | описание |
|------|-------|----------|
| `image` | да | фотография комнаты, JPG/PNG/WebP до 12 МБ |
| `code` | да* | артикул оттенка ArchiPaint, например `AP-0118` |
| `color` | да* | цвет стен в HEX (`#RRGGBB`); синонимы полей — `hex`, `wall_color` |

\* нужно одно из двух. Если пришли оба, побеждает `code`: раз клиент выбрал
оттенок в палитре, красить надо ровно тем HEX, что лежит в каталоге, а не тем,
что доехало из браузера. Неизвестный артикул — ошибка `color_unknown`.

Ответ:

```json
{
  "ok": true,
  "jobId": "260826-ab12cd34",
  "resultImageUrl": "/upload/archicolor/out/2026/08/260826-ab12cd34-1.jpg",
  "sourceImageUrl": "/upload/archicolor/in/2026/08/260826-ab12cd34.jpg",
  "provider": { "name": "decor8.ai", "method": "change_wall_color", "mode": "url" },
  "wall": {
    "requested": { "hex": "#EBE1D6", "code": "AP-0118", "name": "Ванильный крем",
                   "collection": "ArchiPaint Nord", "lrv": 76.4 },
    "rendered":  { "hex": "#F1E7DD", "lrv": 81.1, "lab": [92.23, 1.58, 6.41],
                   "sharePct": 100, "role": "Основной тон стены", "matches": [ … ] },
    "deltaE": 1.37,
    "quality": "Точное совпадение",
    "coverage": { "changedPct": 32.9, "sampled": 26215, "wallSamples": 8636, "fallback": false },
    "colors": [
      {
        "hex": "#F1E7DD", "sharePct": 100, "lrv": 81.1, "role": "Основной тон стены",
        "matches": [
          { "code": "AP-0118", "name": "Ванильный крем", "hex": "#EBE1D6",
            "collection": "ArchiPaint Nord", "deltaE": 1.37,
            "quality": "Точное совпадение", "qualityCls": "good", "lrv": 76.4 }
        ]
      }
    ]
  },
  "freeLeft": 9, "balance": 0, "pricePerImage": 149, "elapsed": 8.4
}
```

`wall.deltaE` — главное число этой страницы: насколько краска на фотографии
расходится с выкрасом каталога. Расхождение нормальное, его создаёт освещение
комнаты; показывать его честнее, чем делать вид, что снимок равен выкрасу.

`colors` на верхнем уровне дублирует `wall.colors` — там тона стены: основной,
на свету и в тени. Это один и тот же оттенок при разном освещении, а не разные
краски.

Многовариантности здесь нет: `/change_wall_color` возвращает один кадр,
поэтому поля `num_images` и `seed` у этого эндпоинта больше нет.

### GET /api/archicolor/quota

```json
{ "ok": true, "freeLeft": 9, "freeTotal": 10, "pricePerImage": 149,
  "balance": 0, "canGenerate": true, "configured": true, "maxUploadMb": 12 }
```

Нужен только для подписи на кнопке. **Настоящая проверка лимита — в `generate`**,
фронтенду здесь верить нельзя.

### POST /api/archicolor/analyze

Разбор изображения на цвета без генерации: `jobId` готовой генерации либо
файл `image`. Генерации не тратит — это чистый расчёт по нашему каталогу.

### Ошибки

Единый формат, HTTP-код осмысленный:

```json
{ "ok": false, "error": { "code": "quota_exceeded", "message": "Бесплатные генерации закончились…" } }
```

| код | HTTP | когда |
|-----|------|-------|
| `color_missing` | 422 | клиент не выбрал цвет (или HEX не разобрался) |
| `color_unknown` | 422 | такого артикула нет в палитре ArchiPaint |
| `upload_missing`, `upload_type`, `upload_too_large` | 400–415 | проблема с файлом |
| `quota_exceeded` | 402 | лимит исчерпан, платить нечем |
| `rate_limited` | 429 | слишком много запросов с одного IP |
| `provider_invalidinput` | 502 | Decor8 не смог разобрать фотографию |
| `provider_invalidparameters` | 502 | Decor8 не принял состав параметров |
| `provider_timeout` | 504 | генерация не уложилась в таймаут |
| `provider_not_configured` | 503 | не задан ключ |

Текст `message` написан для клиента — его можно показывать как есть.
Технические подробности уходят в `upload/archicolor/.state/archicolor.log`
и попадают в ответ только при `'debug' => true`.

## Имя поля с цветом

Источники Decor8 расходятся: страница документации показывает в теле запроса
`wall_color_hex_code`, а их же Python- и JS-SDK принимают аргумент
`wall_color_hex`. Проверить это без боевого ключа нельзя, поэтому клиент
отправляет документированное имя, а если провайдер отвечает, что не понял
параметры, — повторяет запрос со вторым именем и пишет об этом в лог
(`decor8_retry_color_key`).

Когда станет понятно, какое имя настоящее, поставьте его в конфиге —
и лишнего запроса не будет:

```php
'decor8_wall_color_key' => 'wall_color_hex_code',
```

## Полная перегенерация комнаты

`Decor8Client::generateDesignsForRoom()` и `PromptMapper` остались в
библиотеке: это другой сценарий — перерисовать комнату целиком по текстовому
заданию («спальня в скандинавском стиле, тёплые тона»). `PromptMapper`
превращает русский текст в англоязычный промпт и перечисления `room_type` /
`design_style`, потому что текстовый энкодер модели кириллицу понимает плохо.

Визуализатор стен этот путь не вызывает. Если сценарий перегенерации не нужен,
оба файла можно удалить — на страницу `/AI` это не повлияет.

## Как фото попадает в Decor8

Два способа, выбор задаёт `decor8_input_mode`:

* **`url`** — фото сохраняется у нас и передаётся ссылкой `input_image_url`.
  Требует, чтобы сайт был доступен из интернета.
* **`multipart`** — файл уходит полем `input_image`. Работает всегда,
  в том числе на закрытом стенде.
* **`auto`** (по умолчанию) — `url`, если `public_base_url` похож на боевой
  домен, иначе `multipart`. Если провайдер отказался принимать фото,
  автоматически пробуется второй способ.

## Лимиты и оплата

По умолчанию 10 бесплатных примерок на пользователя за 30 дней плюс потолок
20 запросов в час на IP. Авторизованный пользователь Bitrix считается по своему
ID, гость — по метке в cookie; потолок на IP закрывает подбор cookie.

Примерка списывается **до** обращения к Decor8 и **возвращается**, если
провайдер её не выполнил: клиент не платит за чужую неудачу.

Платные примерки включаются двумя хуками в `config.local.php` —
`balance_provider` и `balance_charge`. Без них, когда бесплатные закончатся,
кнопка просто заблокируется.

## Что настроить перед запуском

- **Товары.** В `ai/index.php` варианты покупки (выкрас, пробник, банка) заданы
  примерными ценами, а корзина живёт в браузере. Подставьте реальные позиции
  каталога и определите `window.archicolorAddToBasket`, чтобы класть цвет
  в корзину Bitrix.
- **Модерация.** Загруженные фотографии не модерируются на нашей стороне.
  Decor8 отклоняет часть материала сам, но если сервис публичный, добавьте
  свою проверку. Текстовых полей у визуализатора нет — клиент выбирает цвет
  из каталога, поэтому произвольный текст в провайдер не уходит.
- **Каталог.** `assets/js/podbor.palette.js` — справочный набор из 288 оттенков,
  Lab рассчитан из sRGB. Для честного ΔE подставьте выгрузку спектрофотометра
  в `data/archipaint-palette.json` — формат записи тот же, PHP прочитает её первой.

# Задание для ArchiColor AI

Кнопка **«Промпт для ArchiColor AI»** в ряду под интерьерной палитрой
собирает всё, что страница уже посчитала — базовый цвет, гармоническую
схему, характер гаммы, роли и доли площадей, — в готовое задание на
перекраску фотографии клиента.

Точка входа: `D.buildAiPrompt(data, scheme, opts)` в
`assets/js/podbor.data.js`. Функция чистая, DOM ей не нужен — её можно
дёрнуть из Node и из бэкенда.

---

## Почему текст и JSON, а не только текст

Текстовый промпт задаёт сцену, покрытие и перечень запретов. Точный цвет
он не задаёт и задать не может: ни Decor8, ни любой другой генеративный
движок не попадёт в `#A85540` по словесному описанию — попадёт «примерно
туда». Для сервиса, который продаёт колеровку по артикулу, «примерно» не
работает.

Поэтому задание состоит из двух частей:

| Часть | Что делает | Куда идёт |
|---|---|---|
| `prompt` + `negative` | сцена, покрытие, что нельзя трогать | в движок |
| `payload.surfaces` | поверхность → HEX + артикул каталога | в шаг перекраски |

**Перекраска ведётся по JSON**, промпт работает вторым слоем. Если
конвейер устроен как гибрид (маски + Lab-перекраска из
`podbor.photo.js`), `surfaces` подставляется в него напрямую и цвет
получается точным до `ΔE < 1`.

## Сигнатура

```js
D.buildAiPrompt(data, scheme, {
  roomId: 'bedroom',              // living | dining | kitchen | bedroom | office
  finish: 'deep matt emulsion'    // необязательно
})
// → { prompt, negative, ru, payload, rows }
```

- `data` — результат `buildInteriorPalettes`;
- `scheme` — один элемент `data.results`.

| Поле | Назначение |
|---|---|
| `prompt` | английский промпт для движка |
| `negative` | негативный промпт |
| `ru` | то же по-русски — оператор читает перед отправкой |
| `payload` | JSON-задание целиком, включая `prompt` и `negativePrompt` |
| `rows` | разобранные строки поверхностей, из них строится UI |

### Почему промпт английский

В основе archicolor-ai стоит Decor8. Он обучен на английских описаниях
интерьеров; на русском половина указаний до него не доходит. Русская
версия (`ru`) существует ровно для того, чтобы человек мог проверить
задание перед отправкой, и в движок не уходит.

## Карта поверхностей

Роли палитры ложатся на те же поверхности, что и маски в
`podbor.photo.js` (`AI_SURFACES`):

| Роль | `surface` | В промпте |
|---|---|---|
| `main` | `wall` | walls |
| `accent` | `accentWall` | feature wall |
| `additional` | `furniture` | upholstered furniture |
| `deep_accent` | `door` | door leaf |
| `ceiling` | `ceiling` | ceiling |
| `trim` | `trim` | skirting, architraves and trim |

Пол (`floor`) в палитру не входит и в задании стоит в списке «не
трогать».

## Формат `payload`

```json
{
  "service": "archicolor-ai",
  "task": "recolor",
  "version": 1,
  "room": "bedroom",
  "finish": "deep-matt",
  "harmony": {
    "scheme": "triad", "schemeLabel": "Триада",
    "preset": "luxury_dark", "presetTitle": "Тёмная база",
    "baseColor": "#2F6F8F", "baseRole": "main",
    "contrast": "Высокий контраст", "spreadL": 68.9
  },
  "surfaces": [
    { "surface": "wall", "role": "main", "hex": "#2F6F8F",
      "code": "AP-0922", "name": "Сапфир", "lrv": 14, "areaShare": 63 }
  ],
  "keep": ["geometry", "layout", "furniture_shapes", "lighting",
           "window_view", "floor", "glazing"],
  "prompt": "…", "negativePrompt": "…"
}
```

`version` поднимается при любом несовместимом изменении формата —
бэкенду есть на что смотреть.

`areaShare` — доля площади по контрасту площади Иттена, уже с поправкой
на светлоту тонов. Она не равна плоским 60/30/10 и суммируется ровно в
100 по трём весомым ролям; у потолка и столярки доли нет.

## Английские имена оттенков

Движку нужно словесное описание цвета: `describeEn(lch)` собирает его из
светлоты, хромы и тона — «mid-tone soft petrol blue», «near-white muted
beige».

Границы тонов заданы **по кругу LCh, а не HSL**. В Lab опорные точки
стоят иначе, чем подсказывает интуиция:

| Цвет | Угол LCh |
|---|---|
| красный | 40 |
| оранжевый | 60 |
| жёлтый | 103 |
| зелёный | 136 |
| бирюзовый | 196 |
| синий | 306 |
| маджента | 328 |

Шкала «через 30°», привычная по HSL, на этих углах называет цвета
неверно: чистый синий уезжает в «пурпурный», а олива — в «жёлтый».

Два имени углом не задаются и разобраны отдельно: жёлтый отличается от
оливы только светлотой (`L > 85` при `C > 45`), беж — это приглушённая
светлая охра (`L > 70` при `C < 22`). При хроме ниже 10 тон называется
серым с указанием подтона — тёплый он или холодный: для стены это
важнее самого тона.

## Открытые вопросы к archicolor-ai

1. **Возвращает ли сервис маски поверхностей?** От этого зависит, работает
   конвейер гибридом (маски + точная Lab-перекраска) или только
   генерацией. Гибрид даёт точный артикул, генерация — только похожий
   цвет.
2. **Референсы.** Промпт описывает окрашиваемые поверхности. Фотографии
   пола, дверей, текстиля и мебели, которые клиент загружает отдельно,
   идут мимо этого задания — их место в конвейере надо описать, когда
   будет ясен ответ на первый вопрос.
